# 【健康教育】母乳储存的注意事项

> 更新时间：2026-09-17 (UTC+8)

**母乳分冷藏和冷冻两种保存方式****1**冰箱冷藏

**挤出来的母乳在0-4℃的条件下可保存8天。**需要特别注意的是：如果冰箱的冷藏温度不能保证稳定在这一范围，则最好控制在**24小时之内**，在炎热的夏天更应如此。
**2**冰箱冷冻

母乳的冷冻保藏时间与冷冻箱的状况密切相关，对于单独隔离开来的温度在**0℃以下的冷冻室**，如果经常需要开关门拿取物品，保质期不可超过3—4个月;

如果是深度冷冻室，即温度长期保持在-15℃~-18℃以下，且不经常开关门的情况下，保质期可达六个月甚至更长。

储存注意事项：
1、母亲在挤奶前必须洗手 ;

2、乳汁可以在冰箱中冷藏储存或者冷冻储存。请将吸出的乳汁放在奶瓶中密封盖好，或者放在母乳存储杯中并盖好 ;

3、必须使用消毒过的吸奶器吸奶 ;

4、乳汁吸出后必须马上冷藏 ;

5、每一瓶的乳汁上都要注明当天的日期；

6、乳汁在冰箱中冷藏储存48小时(不要放置在冰箱门上)，冷冻储存3个月 ;

7、不要将解冻后的母乳再次冷冻 ;

8、不要在冷冻保存的乳汁中加入新鲜乳汁；

9、不要使用玻璃容器或金属容器保存母乳，容器内母乳不要装的过满。

**注**
母乳储存一段时间后会出现正常的分解现象，颜色可能会有轻微的发蓝、发黄或者发棕色，妈妈们不必太过担心。

如何解冻母乳
冷冻的母乳在解冻时，最好的办法，是提早将母乳保鲜袋自冰箱的冷冻柜中取出，然后放入冷藏柜。

如果要当场将冷冻的母乳解冻，应该先用冷水冲洗密封袋，逐渐加入温水，直至母乳完全解冻并升至适宜哺喂的温度。

解冻后的母乳一定要在24小时内吃掉，并且不能再次冷冻，最好不要给宝宝喂剩奶。

 如何给母乳加热 

冷藏或冷冻的母乳自然解冻后，可以用婴儿食品加热器、温奶器或用温水加热，水温不宜超过50℃，直至母乳完全解冻，回温到接近体温、不冰冷、适宜哺喂的温度就可以了。

**千万不要将母乳倒入锅内直接用炉火或者微波炉加热！****不正确的加热方法会破坏母乳里的营养成分。**

炉火不适合加热母乳的原因是因为温度太高，会破坏母奶内的活细胞和抗体。
