# 【科普】好不容易“怀孕”了，却总也看不到宝宝，到底怎么回事？

> 更新时间：2026-09-17 (UTC+8)

近日，备孕了快一年的黄女士发现自己怀孕了，喜出望外的她到社区医院查血HCG，证实确实怀孕了，但超声医生告诉她，未看到胚胎，需一周后再复查。

黄女士怀着忐忑的心情等待了一周，复查超声仍未见到胚胎，好在血HCG值翻了好几倍，于是黄女士耐着性子，隔了五天再次就诊。但令她失望的是，虽然血HCG值增长明显，但超声检查仍未见到胚胎。

这下黄女士坐不住了，找到了妇幼保健院的劳金美主任看诊，劳主任仔细询问了病史，此时黄女士已停经2+月，血HCG值上升到了4.8万，阴道B超提示：宫内膜1.9cm，回声不均匀，内见多个小暗区，双侧附件区未见异常。这种情况引起了劳主任的警觉，凭借着丰富的经验判断此次妊娠葡萄胎或者滋养细胞肿瘤可能性大，于是安排黄女士马上住院并在入院当天进行了清宫治疗，术后病理回报：**完全性葡萄胎。**

**葡萄胎到底是怎么回事？**

问

**什么是葡萄胎？**

答

葡萄胎是因妊娠后胎盘绒毛滋养细胞增生、间质水肿、而形成大小不一的水泡，水泡间借蒂相连成串，形如葡萄而名之，也成水泡状胎块（hydatidiform mole）。

可分为完全性葡萄胎及部分性葡萄胎两种类型。

问

**葡萄胎形成的原因有哪些？**

答

葡萄胎是由于异常受精卵发育而成的，人类体细胞为二倍体，包含23对染色体，每对染色体的一条来自父亲另一条来自母亲，核型为46XX或46XY。

 

 完全性葡萄胎的染色体核型为二倍体，可分为两组染色体均来源于父系（AnCHM）以及两组染色体分别来自父亲和母亲的双亲来源（BiCHM）。

AnCHM中90%为 46XX，由一个细胞核基因物质缺失或失活的空卵与单倍体精子（23，X）受精，经自身复制为二倍体；另有10%核型为46，XY，认为系由一个空卵分别和两个单倍体精子（23，X）及（23，Y）受精而成。

BiCHM约占完全性葡萄胎的20%，常与家族性复发性葡萄胎相关。该类葡萄胎的发生与母亲染色体片段的基因突变有关。

 

 90%的部分性葡萄胎的染色体核型为三倍体，最常见的核型是69，XXY，为一条看似正常的单倍体卵子和两个单倍体精子受精，或者一条看似正常的单倍体卵子（精子）和一个减数分裂缺陷的双倍体精子（卵子）受精而成，所以多余的一套染色体来自父方。

问

**葡萄胎的高危因素有哪些？**

答

营养状况（维生素A及其前体胡萝卜素素缺乏、动物脂肪缺乏）、年龄（＞35岁2倍风险，＞40岁7.5倍风险，＞50岁发生超过三分之一，以及小于20岁者）、社会经济因素、种族、地域、既往葡萄胎病史、流产史和不孕史等均为可能高危因素。

问

**葡萄胎有什么表现？**

答

停经、妊娠反应（较正常妊娠严重）、不规则阴道出血 （一般发生在停经8-12周）、腹痛、腹胀 （葡萄胎增长迅速、子宫过度快速扩张所致，通常出现在阴道出血前）、妊娠早期血压增高（早孕合并子痫）、甲亢症状：约10%葡萄胎患者出现轻度甲亢（心慌、皮肤潮湿、震颤等）、卵巢黄素化囊肿等。

问

**葡萄胎如何诊断？**

答

凡停经后不规则阴道流血、子宫大于停经月份，要考虑葡萄胎可能。若在妊娠早期出现子痫前期或甲亢征象，妊娠呕吐严重、双侧卵巢囊肿，及阴道排出物中见到水泡状组织等均支持诊断，可选择超声检查及血HCG测定进一步明确诊断。

问

**葡萄胎要与什么疾病相鉴别？**

答

葡萄胎需与先兆流产、剖宫产术后子宫疤痕妊娠、双胎妊娠等疾病相鉴别。

问

**葡萄胎如何处理？**

答

葡萄胎一经临床诊断，应及时清宫，小于12周者可一次清干净，大于12周者或者术中感觉一次刮净有困难时可于一周后行第二次清宫。

预防性化疗：仅用于有高危因素及随访困难的完全性葡萄胎患者。

子宫切除：年龄接近绝经、无生育要求者可进行，但手术不能防治子宫外转移，且术后仍需随访，故不作为常规治疗方式。

问

**葡萄胎的随访？**

答

随访目的：早期发现恶变，早期治疗。随访期1年。

问

**普通人应该怎么预防葡萄胎的发生？**

答

从病因来看，不管是完全性葡萄胎还是部分性葡萄胎都与母系基因缺失、父系基因物质增加有关；从高危因素来看，葡萄胎的发生与母亲的妊娠年龄、营养状况、经济情况等密切相关。所以女性选择合适的生育年龄、加强锻炼、提高体质、保证均衡的营养是避免异常妊娠的最佳方式。
